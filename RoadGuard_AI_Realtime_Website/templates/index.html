MATHWORKS AUTONOMOUS DRIVING TOOLBOX ECOSYSTEM

Architectural Mapping of MathWorks Tools & Simulink Subsystems

Formal specification of the 7 core MathWorks tools utilized in the autonomous driving perception, control, and simulation pipeline.

7 TOOLBOXES DEFINED
🛣️ 1. RoadRunner

Road Environment & Scenario Authoring

High-fidelity 3D modeling of unstructured Indian road scenes with missing lane markers, non-standard curb boundaries, and complex junctions. Exports OpenDRIVE (ASAM) network descriptions for map matching.

ASAM OpenDRIVE Unstructured Roads
📡 2. Automated Driving Toolbox

Sensor Simulation & Multi-Object Tracking

Camera, radar, and LiDAR sensor fusion blocks. Generates synthetic detections, cuboids, and multi-object tracking filters (JPDA / GNN / Kalman) to benchmark against vision pipelines.

Sensor Fusion Ground-Truth Cuboids
🧭 3. Navigation Toolbox

Kinodynamic Path & Trajectory Planning

Dynamic lattice planners, Costmap2D obstacle representation, and Hybrid A* algorithms. Evaluates quintic polynomial lateral candidates to plan optimal collision-free evasion paths around road blockages.

Costmap2D Hybrid A* Lattice
⚙️ 4. Stateflow

Supervisory Decision & Safety State Machine

Formal finite state machine (FSM) governing safety-critical mode transitions (NORMAL ➔ CAUTION ➔ SLOW DOWN ➔ STOP / REPLAN). Integrates hysteresis timers to eliminate alert flickering.

Decision FSM Hysteresis Debounce
🏎️ 5. Vehicle Dynamics Blockset

Chassis Dynamics & Tire Force Modeling

Nonlinear 3-DOF and 14-DOF chassis motion dynamics including longitudinal acceleration, brake load transfer, Pacejka magic formula tire curves, and yaw damping.

Pacejka Tires 3-DOF / 14-DOF
📐 6. Simulink Bicycle Model

Bicycle Model Kinematic & Dynamic Solver

Closed-form mathematical vehicle model mapping steering input angle δ_f to lateral position, yaw rate r, and sideslip angle β. Solved continuously via 4th-order Runge-Kutta (RK4) integration.

RK4 Numerical Solver Yaw & Slip Angle
🧠 7. Deep Learning Toolbox

Neural Network Deployment & ONNX Import

Imports PyTorch and ONNX neural network weights into Simulink via importNetworkFromPyTorch and importONNXFunction for hardware-in-the-loop (HIL) execution and code generation.

ONNX Subsystems Embedded C/C++ Code
